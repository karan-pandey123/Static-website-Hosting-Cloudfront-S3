# AWS Static Website Hosting with CloudFront & S3

A production-grade static website hosting solution using AWS S3 for storage and CloudFront for global content delivery, featuring optimized caching, HTTPS security, and DDoS protection.

 🎯 Overview

This project demonstrates enterprise-level static website deployment on AWS:
- **Amazon S3** for scalable object storage
- **CloudFront** for global content delivery network (CDN)
- **SSL/TLS certificates** for HTTPS security
- **Access control** and bucket policies
- **Caching optimization** for performance
- **DDoS protection** via CloudFront shield

 ✨ Key Features

** Global Content Delivery** - CloudFront edge locations worldwide  
** High Availability** - Redundant storage and distribution  
** Security** - HTTPS encryption and origin access identity  
** Performance** - Optimized caching strategies  
** Scalability** - Handles traffic spikes automatically  
** Cost-Effective** - Pay-per-use pricing model
